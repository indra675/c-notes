3. Part A: C language topics in detail

1. Basics and data types

  • Compile and run cycle (source, compiler, executable)
  • int, char, float, double, sizeof
  • Variables, constants, type casting
  • printf / scanf and format specifiers

Practice: Print the size of every data type and add two numbers typed by the user.

2. Operators and control flow

  • Arithmetic, relational, logical, ternary operators; precedence
  • if / else if / else, switch
  • for, while, do-while, break, continue

Practice: Calculator using switch; leap year; prime check; pyramid patterns.

3. Functions and recursion

  • Declaration, definition, call
  • Call by value and return values
  • Recursion and how the stack grows
  • Header files (split code into .c and .h)

Practice: Factorial, Fibonacci, GCD, power, sum of digits using recursion.

4. Arrays and strings

  • 1D and 2D arrays
  • Strings as char arrays ending in '\0'
  • string.h: strlen, strcpy, strcmp, strcat
  • Searching and sorting basics

Practice: Write your own strlen, strcpy, strcmp; reverse a string; palindrome; matrix addition.

5. Pointers (most important)

  • Address-of (&) and dereference (*)
  • Pointer arithmetic; arrays and pointers are closely related
  • Pointer to pointer, void pointer, NULL pointer
  • Dangling and wild pointers
  • Function pointers and callbacks

Practice: Swap two numbers using pointers; traverse an array using only pointers; call a function through a function pointer.

6. Structures, unions, enums, typedef

  • struct definition and arrays of structs
  • union: members share the same memory
  • enum for named constants
  • typedef to shorten type names
  • Bit-fields

Practice: Student record array; print sizeof a struct and a union and explain the difference.

7. Dynamic memory

  • malloc, calloc, realloc, free
  • Memory leaks and double free
  • Stack vs heap
  • Linked list basics

Practice: Create an array with malloc, grow it with realloc, free it; build a singly linked list (insert, delete, reverse).

8. Storage classes and preprocessor

  • auto, register, static, extern
  • static variable inside a function keeps its value
  • #define, macros with arguments, #ifdef, #ifndef
  • Include guards

Practice: Static counter function; MAX/MIN macros; a project split into 3 files with a header and include guard.

9. File handling

  • fopen, fclose, modes (r, w, a)
  • fprintf, fscanf, fgets, fputs
  • fread and fwrite for binary data

Practice: Save and load student records to a file.

4. Part B: Embedded C topics in detail

10. Bitwise operators and bit manipulation

  • &, |, ^, ~, <<, >>
  • Set, clear, toggle and check a bit using masks
  • Count set bits, check power of 2, swap nibbles, reverse bits
  • Why embedded code uses bit operations on registers

Practice: Write macros SET_BIT, CLEAR_BIT, TOGGLE_BIT, CHECK_BIT and test them.

11. Qualifiers and fixed-width types

  • volatile: tells the compiler a value can change outside the code (hardware, ISR)
  • const and const volatile (read-only status register)
  • static for file-private variables
  • uint8_t, uint16_t, uint32_t from stdint.h

Practice: Explain in your own words why a flag changed in an ISR must be volatile.

12. Memory layout, startup and padding

  • Flash vs RAM
  • Sections: .text, .data, .bss, stack, heap
  • What startup code does before main()
  • Linker script idea
  • Struct padding and alignment
  • Endianness (little vs big)

Practice: Write a program that detects endianness; print struct sizes with and without padding.

13. Registers and hardware access

  • Memory-mapped I/O
  • Pointer to a fixed address: *(volatile uint32_t*)0x40021000
  • Register structs and macros
  • Function pointers for callbacks and drivers

Practice: Simulate a GPIO register in a plain C program and control its bits.

14. GPIO and debouncing

  • Input and output pins, pull-up and pull-down
  • Push-pull vs open-drain
  • Polling
  • Button bounce and software debouncing

Practice: Button toggles an LED with proper debounce (ESP32 or Arduino).

15. Interrupts and ISR

  • Vector table and interrupt priority
  • ISR rules: keep short, no printf, no blocking, use volatile flags
  • Race conditions and critical sections
  • Polling vs interrupt

Practice: Button interrupt that sets a flag; main loop handles the work.

16. Timers, PWM and ADC

  • Prescaler, overflow, compare match
  • Timer interrupt for a periodic task
  • PWM duty cycle and frequency (LED dimming, servo)
  • ADC resolution and sampling

Practice: Blink an LED with a timer (no delay); read a sensor with ADC and dim an LED with PWM.

17. Communication protocols

  • UART: baud rate, start/stop bits, parity
  • I2C: SDA/SCL, address, ACK, pull-up resistors
  • SPI: MOSI, MISO, SCK, CS and modes
  • When to choose which

Practice: Print sensor data over UART; scan I2C addresses; read one SPI device.

18. Embedded design patterns

  • Circular (ring) buffer
  • Finite state machine
  • Watchdog timer
  • Low-power sleep modes
  • Intro to RTOS: tasks, semaphore, queue

Practice: Ring buffer for UART receive; traffic light as a state machine.

6. Interview questions to master

Answer each one out loud in under 1 minute. If you cannot explain it simply, you do not know it yet.

  1. What is the difference between a pointer and an array?
  2. What is a dangling pointer? How do you avoid it?
  3. Difference between malloc and calloc?
  4. What is a memory leak?
  5. What does static do (inside a function, and at file level)?
  6. Difference between struct and union?
  7. What is struct padding? Why does it happen?
  8. What does volatile mean? Give an example where it is needed.
  9. Can a variable be both const and volatile? Example?
  10. How do you set, clear, toggle and check a bit?
  11. How do you check if a number is a power of 2?
  12. How do you detect endianness in code?
  13. What are the .text, .data, .bss sections?
  14. What happens before main() runs on a microcontroller?
  15. What rules should an ISR follow?
  16. Why should you not call printf inside an ISR?
  17. Polling vs interrupt: when to use which?
  18. What is debouncing and how do you do it in software?
  19. Difference between UART, I2C and SPI?
  20. Why do I2C lines need pull-up resistors?
  21. What is PWM and how is duty cycle calculated?
  22. What is a watchdog timer?
  23. What is a circular buffer and where is it used?
  24. What is a function pointer? Where is it used in embedded code?
  25. Swap two numbers without a temporary variable.
